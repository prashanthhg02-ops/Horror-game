# The Quiet Below

A small, browser-based top-down horror escape game. Explore an abandoned
sanatorium, collect three keys, and reach the exit before the creature catches
you. Your flashlight helps reveal the way, but its battery will not last
forever.

## How to play

1. Open `index.html` in a modern web browser.
2. Find all three keys.
3. Reach the exit and avoid the creature.
4. Collect batteries to recharge your flashlight.

## Controls

| Action | Controls |
| --- | --- |
| Move | `W`, `A`, `S`, `D` or the arrow keys |
| Sprint | Hold `Shift` |
| Toggle flashlight | `F` |

## Features

- Maze exploration with wall collisions
- Flashlight with a limited battery and rechargeable pickups
- A creature that roams and pursues the player when it spots them
- Win and lose states with a replay option

No installation or build step is required.
